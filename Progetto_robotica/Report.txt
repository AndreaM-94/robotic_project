Aprile 22
Abbiamo scelto il progetto basato su “Livox-MD-360”.  Passi preliminari:
    1. Installazione di ubuntu 22.04
    2. Installazione di ROS 2 humble
    3. Installazione del sofware LIVOX viewer 2
Collegamento e Setup del sensore lidar
Sudo apt install net-tools

bisogna avviare la connessione con il sensore, quindi bisogna cercare la porta utilizzata dall’ethernet, con il comando:
lshw -class network 

Bisogna inserire il nome logico in :
sudo ifconfig “nome_logico” 192.168.1.50

Download livox viewer2
www.livoxtech.com/mid-360/downloads
Scaricare Livox Viewer 2 per linux, estrarre in una cartella il pacchetto e utilizzare il seguente comando:
./livox_viewer_2.sh.
Sostituire il nome se è diverso.

MAGGIO 4
------------------------------- INSTALLAZIONE DRIVER E SDK-----------------------------
1) PRIMA di collegare il dispositivo, reimpostare l'ip ethernet con "sudo ifconfig nome_logico 192.168.1.50
2) Installare l'SDK con:
        cd ~
        git clone https://github.com/Livox-SDK/Livox-SDK2.git
        cd Livox-SDK2
        mkdir build && cd build
        cmake .. && make -j
        sudo make install
3) Installare i driver LIVOX con:
        mkdir -p ~/ws_livox/src
        cd ~/ws_livox/src
        git clone https://github.com/Livox-SDK/livox_ros_driver2.git
        cd ~/ws_livox/src/livox_ros_driver2
4) Costruzione del pacchetto:
        source /opt/ros/humble/setup.bash
        ./build.sh humble
5) Nel terminale di installazione del driver scrivere il comando:
        nano ~/ws_livox/src/livox_ros_driver2/config/MID360_config.json
    Cambiare tutti gli IP con quello impostato nel passo 1.
    Cambiare l'IP del dispositivo con 192.168.1.106
